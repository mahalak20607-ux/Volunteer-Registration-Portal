# Volunteer Registration Portal

A simple and user-friendly web application designed to help volunteers register for events, manage their information, and explore available volunteering opportunities.

## 🌟 Features

* 📝 Volunteer Registration
* 🔐 User Login
* 📊 Volunteer Dashboard
* 📅 Event Information
* 📞 Contact Form
* ℹ️ About Page
* 📱 Responsive and user-friendly interface
* 🎨 Clean and professional UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/mahalak20607-ux/Volunteer-Registration-Portal.git
```

2. Open the project folder in **VS Code**.

3. Open `index.html`.

4. Run the project using **Live Server** or open `index.html` directly in your browser.

## 🎯 Purpose

The main purpose of this project is to provide an easy-to-use platform where users can register as volunteers and access information about volunteering events.
